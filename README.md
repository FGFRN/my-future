# 我与我的未来 | My Future

> 一段关于自我探索、技术学习与未来成长的旅程。

这是一个以 **「我与我的未来」** 为主题开发的个人介绍网站，旨在通过网页的形式展示我的个人信息、目前掌握的技术、未来发展规划，以及希望在 Java 俱乐部中学习和探索的方向。

项目采用深色科技风格，以蓝紫色渐变作为视觉主题，并结合动态文字、滚动动画和交互式时间轴，让个人介绍不再局限于静态的文字展示。

##  网站功能

### 1. 个人介绍

展示个人基本信息、专业背景与兴趣方向，通过简洁的布局帮助访问者快速了解我。

### 2. 技术能力展示

介绍目前正在学习和使用的技术，包括：

- **Python**：编程基础与算法练习
- **C 语言**：程序设计与数据结构学习
- **HTML / CSS**：网页结构与界面设计
- **JavaScript**：前端交互与动态效果

### 3. 未来成长时间轴

通过可交互的时间轴展示不同阶段的学习与发展目标，包括专业基础、项目实践、技术探索以及升学规划。

时间轴支持点击展开和收起，让访问者可以按照自己的兴趣了解不同阶段的计划。

### 4. 俱乐部学习展望

展示希望在 Java 俱乐部中进一步学习的内容：

- Java 与 Web 后端开发
- 数据库及相关工程技术
- 算法、人工智能与项目实践
- Git / GitHub 与团队协作

### 5. 页面交互与视觉效果

- 深色科技风格与蓝紫渐变设计
- 首页动态打字效果
- 页面滚动渐入动画
- 可展开的交互式成长时间轴
- 导航栏当前区域高亮
- 响应式布局，适配不同屏幕尺寸

##  本地运行

本项目无需安装额外依赖。

1. 克隆仓库：

   ```bash
   git clone https://github.com/FGFRN/my-future.git
   ```

2. 进入项目目录：

   ```bash
   cd my-future
   ```

3. 使用浏览器打开 `index.html`，即可查看网页。

也可以使用 VS Code 的 Live Server 扩展启动本地预览。

##  项目设计思路

在设计这个网站时，我希望它不仅是一份在线个人简介，也能成为记录自己学习与成长过程的空间。

因此，网站以 **「现在的我 → 正在学习的我 → 未来的我」** 为主要叙事思路，将个人介绍、技术能力与未来规划联系起来。

在视觉设计方面，我选择深色背景与蓝紫色渐变，希望呈现具有科技感但不过于复杂的界面。

在交互设计方面，我使用 JavaScript 实现动态文字、滚动动画和时间轴展开功能，希望在提升浏览体验的同时，加深自己对前端开发的理解。
